## 既知の制限事項

- PostgreSQLの `id` シーケンスは `init.sql` で手動INSERT後に `setval` でリセットしている。既存の起動済みDBを使う場合は手動で以下を実行する必要がある。

```sql
SELECT setval('users_id_seq', (SELECT MAX(id) FROM users));
```
