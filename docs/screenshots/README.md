# スクリーンショット

このディレクトリには各画面のスクリーンショットを格納する（`features.md` から参照）。

- signup.png — サインアップ画面
- signin.png — サインイン画面
- memo-list.png — メモ一覧画面
- memo-new.png — メモ新規作成画面
- memo-edit.png — メモ編集画面
- memo-delete-dialog.png — 削除確認ダイアログ

動作確認はブラウザ上で実施済み（サインアップ→サインイン→メモ作成→一覧表示→編集→削除確認ダイアログ→削除→ログアウトの一連のフローを確認）。ただし本セッションで使用したツールでは、ブラウザプレビューのスクリーンショットをこのディレクトリへ画像ファイルとして自動保存することができなかったため、上記ファイルは未配置。手動でスクリーンショットを撮影し、このディレクトリに配置すること。
