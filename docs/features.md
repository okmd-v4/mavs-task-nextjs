# 機能説明書

スクリーンショットは `docs/screenshots/` を参照。

## 1. サインアップ (`/signup`)

- ユーザー名・メールアドレス・パスワード・パスワード（確認）を入力して新規登録する。
- クライアント側は react-hook-form による必須チェック・パスワード6文字以上チェックを行う。
- サーバー側でも同様のバリデーション（全項目必須／パスワード6文字以上／確認一致／メールアドレス重複）を行う。
- 登録成功後、3秒後に自動的に `/signin` へ遷移する。
- スクリーンショット: `docs/screenshots/signup.png`

## 2. サインイン (`/signin`)

- メールアドレス・パスワードを入力してサインインする。
- 成功するとJWTトークンを `localStorage` に保存し、トップページ（メモ一覧）へ遷移する。
- 失敗した場合はフォームがリセットされる。
- サインアップページへのリンクを設置。
- スクリーンショット: `docs/screenshots/signin.png`

## 3. メモ一覧 (`/`)

- ログインユーザーが作成したメモをカード形式のグリッドレイアウトで一覧表示する（作成日時の降順）。
- 状態表示: 読み込み中／エラー／メモが0件の場合の空状態メッセージ。
- 各カードに「編集」「削除」ボタンを設置。
- ヘッダーにログイン中のメールアドレスと「ログアウト」ボタンを表示。
- スクリーンショット: `docs/screenshots/memo-list.png`

## 4. メモ新規作成 (`/memo/new`)

- タイトル（最大100文字、文字数カウンター付き）と本文を入力して保存する。
- 保存後は一覧ページへ遷移する。
- キャンセルボタンで一覧ページへ戻る。
- スクリーンショット: `docs/screenshots/memo-new.png`

## 5. メモ編集 (`/memo/[id]`)

- 対象メモのタイトル・本文を初期値としてフォームに表示する。
- 他ユーザーが作成したメモや存在しないメモにはアクセスできない（404）。
- 保存後は一覧ページへ遷移する。
- スクリーンショット: `docs/screenshots/memo-edit.png`

## 6. メモ削除

- 一覧画面の「削除」ボタン押下で確認ダイアログを表示する。
- 「削除する」を押すとAPIへ削除リクエストを送信し、一覧を再取得する。
- 「キャンセル」でダイアログを閉じる。
- スクリーンショット: `docs/screenshots/memo-delete-dialog.png`

## 7. ログアウト

- ヘッダーの「ログアウト」ボタン押下で `localStorage` のトークンとログイン状態を破棄し、トップページへ遷移する。
